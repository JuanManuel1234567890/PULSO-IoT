# Elementos pendientes para completar la publicación

1. Exportar desde el Node-RED real el flujo utilizado y añadirlo como `node-red/flows.json`, revisando y retirando credenciales/datos privados.
2. Confirmar el nombre de usuario de GitHub, el nombre definitivo del repositorio y su visibilidad.
3. Confirmar que los tres integrantes autorizan la publicación de informe, presentación y fotografías; el repositorio se recomienda inicialmente privado hasta esa confirmación.
4. Confirmar si se desea añadir una licencia abierta.
5. Si se desea reproducibilidad total, añadir versión de Arduino IDE/core ESP32, versión PubSubClient, versión Mosquitto, versión Node-RED y export del dashboard.
